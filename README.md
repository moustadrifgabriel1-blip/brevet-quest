# Brevet Quest

Jeu de révision du Brevet fédéral de spécialiste de réseau, hors technique de mesure (AE07) qui a son propre jeu.

25 chapitres, 338 questions, 77 briefings, 4 laboratoires, 9 mondes. Contenu tiré des supports AA03, AA04, AA05, AA06, AA07, AA08, AE01, AE02, AE03, AE09, AE10, AE12 et AE13.

Chaque question porte un champ `src` avec le module et la section dont elle est tirée. Le script `verifier.js` du dossier source confronte automatiquement chaque question au texte de son module.
